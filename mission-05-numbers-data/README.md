## understanding
binary is base 2 and hexadecimal is base 16
repeated division by 2 gives binary remainders read upwards
repeated division by 16 gives hexadecimal remainders read upwards
place values are used to convert back to decimal
text encoding maps letters and symbols to numbers so computers can store text
