# task 3.4 - operating-system responsibilities

| responsibility | what the os does | simple example |
| --- | --- | --- |
| process management | starts schedules and stops running programs sharing cpu time | running browser and text editor at the same time |
| memory management | allocates ram memory to active programs and frees it on exit | allocating memory to open application tabs |
| device management | manages communication between software and hardware using drivers | sending print jobs to a connected printer |
| file management | organizes files and folders on storage drive and handles reading and writing | opening and saving files in terminal-practice |
| user interface and shell | provides gui and command line interface for user interaction | terminal command line shell and desktop window manager |
| security and permissions | enforces user accounts and file access permissions | preventing unauthorized users from editing system files |
