# task 7.3 - what happens when a website opens

1. user types website name in web browser client
2. browser asks dns server to resolve domain name into an ip address
3. dns server returns numerical ip address of web server to client
4. client initiates connection request packets routed through local router and internet
5. client browser and web server establish connection using https protocol
6. web server processes request and returns webpage data packets
7. client browser renders html css and javascript to display website on screen
