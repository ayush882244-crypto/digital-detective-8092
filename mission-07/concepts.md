# task 7.1 - network concepts

| concept | explanation | example |
| --- | --- | --- |
| lan | local area network connecting devices in a small area | home wifi network connecting laptop and phone |
| man | metropolitan area network connecting networks across a city | college campus network linking academic buildings |
| wan | wide area network connecting networks across countries | the global internet |
| dns | domain name system translating website names to ip addresses | resolving example.com to its public ip address |
| router | network device forwarding data packets between different networks | home router connecting local devices to isp |
| protocol | agreed set of rules for communication between devices | https protocol for secure web browsing |
| packet switching | dividing data into small packets that travel independently across network | webpage data transmitted in packets |
| client-server | model where client requests service and server delivers it | web browser requesting webpage from web server |
