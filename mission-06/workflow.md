# mission 6 - git workflow notes

## task 6.1 - status staging commit and history
git status shows current branch and modified or untracked files
git add moves selected file changes into the staging area
git commit records staged changes into repository history with a message
git log displays past commit history

## task 6.2 - branch and readme change
created branch update-about to work on learning notes separately from main
added my learning section to root readme and committed change on update-about

## task 6.3 - pull request
a pull request asks for branch changes to be reviewed before merging into main
it allows team members to review code and discuss changes before combining branches

## task 6.4 - git glossary
| term | one line explanation |
| --- | --- |
| init | git init starts a new git repository in the current folder |
| status | git status shows current branch and file change states |
| stage | git add selects file changes for the next commit |
| commit | git commit records staged changes permanently into history |
| history | git log lists previous commits and messages |
| create / list branch | git branch creates or lists local branches |
| switch branch | git switch or git checkout switches active working branch |
| publish | git push sends local branch commits to remote repository |
| retrieve remote changes | git pull or git fetch downloads updates from remote repository |
