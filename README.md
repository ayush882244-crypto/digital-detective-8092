## run the converters

### python converter
run from repository root:

```sh
python3 mission-05-numbers-data/number_converter.py
```

### bash arithmetic converter
run from repository root:

```sh
bash mission-05-numbers-data/number_converter.sh
```

enter a positive decimal integer when prompted to see binary and hexadecimal results
