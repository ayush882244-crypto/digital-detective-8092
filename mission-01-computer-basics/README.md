### task 1.1 - ipos activity trace: typing and saving a text file
| stage | what happens in your example | possible hardware / component |
| --- | --- | --- |
| input | user presses keys on keyboard to type text | keyboard |
| processing | cpu processes characters and stores them in ram | cpu and memory |
| output | text appears immediately on screen | monitor display |
| storage | file is saved to disk when user clicks save | ssd |

activity flow:
the user types letters which send signals to cpu then cpu puts text into memory and shows it on screen and finally writes file into ssd for permanent storage
