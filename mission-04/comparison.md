# task 4.2 - compilers and interpreters

| point | compiler | interpreter |
| --- | --- | --- |
| when translation / execution happens | translates entire source code before running | translates and runs code line by line at runtime |
| typical output | standalone executable machine code file | direct execution result on screen |
| example | c compiler such as gcc | python interpreter |
| one advantage | faster execution speed once compiled | convenient testing and debugging without build step |

a compiler translates program code before running which produces fast machine code
an interpreter reads and carries out instructions directly at runtime which makes development quick
some languages combine both by compiling to bytecode and running in a virtual machine
