# task 1.1 - trace an activity using ipos

## activity: create and save a text document

| stage | what happens | hardware or component involved |
| --- | --- | --- |
| input | text characters and save commands are typed | keyboard |
| processing | operating system and editor process text using cpu and hold data in ram | cpu and ram memory |
| output | text is rendered on display screen for user to review | monitor display |
| storage | saving writes the file to persistent drive | ssd |

## how the stages connect
text enters as input from keyboard
cpu runs the program instructions using ram to hold active data
monitor displays visual output
when user saves the file operating system writes data to ssd for permanent storage
